## 二、岗位职责（核心职责 4 条）

1. 负责大模型应用落地：基于开源大模型与提示工程，设计与开发智能问答、Agent 工作流、RAG 检索增强等企业级 AI 功能。
2. 负责智能体（Agent）与多智能体协作系统的技术方案设计、编码实现与上线优化，负责 LangGraph / LangChain 框架的应用与二次开发。
3. 负责模型效果评估与调优：建设评测集，跟踪指标（准确率、召回率、延迟、成本），推动模型蒸馏与量化部署优化。
4. 与产品、算法、工程团队协作，支撑 AI 能力在企业业务场景的规模化落地。

## 三、任职要求（技能标准 / 经验 / 学历门槛）

- **学历要求**：硕士及以上学历，计算机、人工智能、软件工程等相关专业。
- **经验要求**：3 年以上算法或大模型应用开发经验；有 RAG、Agent、Prompt Engineering 落地项目者优先。
- **必备技能标准**：
  - Python（熟练）
  - 大模型应用：RAG / Agent / Function Calling / 提示工程
  - 框架：LangGraph 或 LangChain、FastAPI
  - 向量数据库：Milvus 或同类（pgvector/Qdrant）
  - 基础组件：MySQL、Redis、Docker、Git
- **加分技能**：模型微调（LoRA/QLoRA）、分布式推理、llama.cpp / vLLM、K8s。
