## 一、总体架构（三层拓扑）

```
┌─────────────────────────────────────────────────────────────┐
│                     客户端（呈现层）                           │
│  小程序端 uniapp_h5/ (uni-app + Vue3)        员工/考核/学习    │
│  管理端   admin_web/ (Vue3 + Element Plus)   HR/管理员         │
├─────────────────────────────────────────────────────────────┤
│                 API 网关 / 统一入口                            │
├─────────────────────────────────────────────────────────────┤
│                后端服务层  AI_Talent/ (FastAPI)               │
│   ┌─────────── router → service → dao → model ────────────┐   │
│   │  auth │ talent │ assessment │ matching │ training    │   │
│   │  analytics │ message │ audit │ system                │   │
│   └──────────────────────────────────────────────────────┘   │
│   ┌──────────── AI 引擎层  ai/ ──────────────────────────┐   │
│   │  LangChain(RAG/文档处理) · LangGraph(多Agent有状态)  │   │
│   │  五大Agent · RAG知识库 · NL2SQL问数 · Prompt工程     │   │
│   └──────────────────────────────────────────────────────┘   │
│   JWT认证 · RBAC权限 · Pydantic校验 · 统一异常 · 日志审计 · 限流 │
├─────────────────────────────────────────────────────────────┤
│                数据 + 模型 + 对象存储层                         │
│  MySQL(主数据)  Redis(会话/缓存/限流)  Milvus(向量库)          │
│  MinIO(对象存储)  Ollama(本地大模型推理)  Alembic 迁移          │
└─────────────────────────────────────────────────────────────┘
```

**分层原则**：严格 `router(接口) → service(业务) → dao(数据) → model(表)` 单向依赖，禁止跨层直接访问数据库。

## 七、认证与权限（RBAC + JWT）

1. **登录流程**：账号密码 → 校验 → 签发 `access_token(短时)+refresh_token(长时)` → 返回用户信息+权限码
2. **鉴权依赖**：`get_current_user` 解析 token → 校验角色 → `require_perm("talent:query")` 粒度到按钮
3. **数据行级**：普通员工仅可见本人数据；管理员按部门范围过滤（初步按 `dept_id` 归属/授权）
4. **留痕**：登录日志 + 操作日志中间件，统一写 `sys_operation_log`/`audit_log`
5. **安全**：密码 bcrypt 哈希、传输 HTTPS、敏感字段脱敏（证件号/电话）、登录限流（Redis）

## 八、接口规范（前后端契约）

- **统一前缀**：`/api/v1`
- **统一响应包**：`{ "code":0, "msg":"ok", "data":[...], "meta":{page,total} }`
- **统一错误码**：`core/exceptions.py` 集中定义
- **分页参数**：`page` `page_size`；返回 `meta`
- **文档**：FastAPI `/docs`（Swagger），前端据此联调
- **时间格式**：ISO8601；枚举集中 `enum` 类定义
- **鉴权头**：`Authorization: Bearer <token>`

## 十、开发规范要点

1. **禁裸 SQL**：全部数据操作走 SQLAlchemy ORM（复杂统计用 ORM 表达式或受控查询）
2. **异常统一**：业务异常抛 `BizError(错误码)`，全局 `exception_handler` 收敛
3. **日志**：结构化日志（json），请求日志中间件记录 method/path/耗时/uid
4. **配置外部化**：`.env` 管理 DB/Redis/JWT secret，`.env.example` 示例
5. **迁移先行**：模型改动必须生成 Alembic 迁移，禁止手改库结构
6. **接口薄、服务厚**：routers 只做参数绑定与权限，业务逻辑在 service
7. **前端统一**：请求封装 request.js 统一拦截 token 续期、错误提示；鉴权走路由守卫
8. **验收对齐**：里程碑对照 WBS 判定，MVP 主流程 F1-F4 为硬验收，F5-F7 尽力
